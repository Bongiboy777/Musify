# AI Context Folder Structure

This document defines the initial structure for AI-related context in this repository.

## Proposed Structure

```text
ai-context/
├── FOLDER_STRUCTURE.md        # This file (source of truth for structure)
├── prompts/                   # Prompt templates and reusable prompt snippets
├── instructions/              # Agent/system instruction files
├── knowledge/                 # Domain knowledge and reference notes
├── sessions/                  # Session-specific context snapshots
├── outputs/                   # Generated AI outputs for review
└── experiments/               # Experimental ideas and test artifacts
```

## Notes

- Keep files small and focused.
- Prefer Markdown (`.md`) for readability and version control.
- Add a `README.md` inside each subfolder once content is added.
